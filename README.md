# OrbitCard

OrbitCard is a B2B SaaS mobile app for wholesale distributors. It focuses on reorder priorities, order-risk visibility, supplier follow-up, and manager approval before purchase orders are created. This is CyphronTech's OrbitCard case study build.

## Stack

- React Native with Expo
- TypeScript
- AsyncStorage for local persistence
- Mocked demo data — no backend required

## Start

```bash
npm install
npm run start
```

Sign in with the demo account (prefilled): `maya@nrwholesale.co` / `orbit-demo`, or register a new account — both work entirely offline.

## App flow

Login -> onboarding -> Today dashboard -> recommendation detail -> approve PO -> supplier follow-up.

## Screens

Today, Inventory (Stock), Orders, Purchase Orders, Reports, Admin, Activity, Suppliers, Onboarding, Login.
